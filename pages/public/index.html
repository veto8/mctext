McText

A small desktop text vault for the things you type again and again: email replies, shell commands, code snippets, AI prompts and notes. Pick a text, press Copy, and paste it anywhere.

Download latest View source README

What it does

Groups and snippets

Keep texts in groups like Work, Home, Code and AI Prompts. Click a group, then click a snippet.

Presentation-based UI

Each group and snippet is a McCLIM presentation. Clicking a row gives the app the real object, not a row number.

Dark theme

Starts dark with a Quicklisp theme.

Copy to any desktop app

Copy puts the text on the system clipboard. Paste into your browser, editor, terminal or email client.

Session clipboard log

A second window lists clipboard texts seen while the app is open. Click one to save it as a permanent snippet.

Local JSON store

Texts live in ~/.local/share/mctext/mctext.json as versioned documents. No account, no cloud.

Command line

Use --list to see snippets and --copy NAME to copy one without opening the GUI.

Run it

# run from source
sbcl --script main.lisp

# or use the task runner
./ask.sh

# list snippets without a window
./dist/mctext/mctext --list

# copy one without a window
./dist/mctext/mctext --copy "Email reply"

Linux needs wl-copy, xclip or xsel for clipboard copy. macOS uses pbcopy, Windows uses PowerShell.

Quick start

git clone https://github.com/veto8/mctext.git
cd mctext
